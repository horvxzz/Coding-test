## 문제 설명

길이가 같은 배열 `A`, `B` 두 개가 있습니다. 각 배열은 자연수로 이루어져 있습니다.

배열 `A`, `B`에서 각각 한 개의 숫자를 뽑아 두 수를 곱합니다. 이러한 과정을 배열의 길이만큼 반복하며, 두 수를 곱한 값을 누적하여 더합니다.

이때 최종적으로 누적된 값이 **최소**가 되도록 만드는 것이 목표입니다.

> 단, 각 배열에서 `k`번째 숫자를 뽑았다면 다음에는 `k`번째 숫자를 다시 뽑을 수 없습니다.

### 예시

`A = [1, 4, 2]`, `B = [5, 4, 4]`라면 다음과 같이 계산할 수 있습니다.

* `A`에서 첫 번째 숫자인 `1`, `B`에서 첫 번째 숫자인 `5`를 뽑아 곱합니다.

  * 누적된 값: `0 + (1 × 5) = 5`

* `A`에서 두 번째 숫자인 `4`, `B`에서 세 번째 숫자인 `4`를 뽑아 곱합니다.

  * 누적된 값: `5 + (4 × 4) = 21`

* `A`에서 세 번째 숫자인 `2`, `B`에서 두 번째 숫자인 `4`를 뽑아 곱합니다.

  * 누적된 값: `21 + (2 × 4) = 29`

따라서 최종 누적값의 최솟값은 **29**입니다.



배열 `A`, `B`가 주어질 때 최종적으로 누적된 값의 최솟값을 반환하도록 `solution` 함수를 완성해주세요.
